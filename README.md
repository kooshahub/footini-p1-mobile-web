# Footini P1 Mobile Web

نسخه مستقل و بهینه‌شده موبایل P1 برای انتشار استاتیک.

- فایل ورودی: `index.html`
- تصاویر: WebP
- ویدئوها: MP4/H.264، بدون صدا، دارای fast-start و عرض حداکثر 720px
- کتابخانه‌های runtime: محلی در `vendor/`
- برای پیش‌نمایش محلی: `python3 -m http.server 8080`

پروژه اصلی `Footini-Mockup` در ساخت این خروجی تغییر نکرده است.
